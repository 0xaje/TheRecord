Guide to The Record

For creators

Start with a blank draft or a template. Save the terms and create a review invitation. Use your recovery code to reopen your workspace on another device.

For co-signers

Open the invitation with its code. Read the terms, request changes if needed, and download the version you agree to. On Diana, use your registered test signing file to approve.

For verifiers

Open a verification link and select your copy. The site hashes the file locally and checks the fingerprint and approval status on Diana.

The agreement text stays off-chain. Diana records a fingerprint and approval evidence. An amendment needs fresh approvals, and the original remains independently verifiable.
